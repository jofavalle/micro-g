whoever coordinates, through a PR like everything else. The state of each task does not go
here: it lives in the issues and in their PRs. **It is kept short on purpose**: what is no
longer in force is deleted, not piled up.

## Decisions in force

- **2026-11-14. The Claude Code layer is versioned.** `CLAUDE.md`, `BITACORA.md` and
  `.claude/` belong to the team, so that every session starts with the same rules. What is
  personal (`CLAUDE.local.md`, `.claude/settings.local.json`) stays out through `.gitignore`.
- **2026-11-14. The repository is born private**, and goes public only after its whole history
  has been reviewed. In a public repository, rewriting the history removes nothing: GitHub
  keeps serving the old commits by SHA.
- **2026-11-14. No model and no attribution in the layer.** The project's
  `.claude/settings.json` overrides each member's own: a model set there would bind every
  account, so each one chooses it with `/model`. Attribution is empty and the use of AI is
  declared in every PR.
- **2026-11-14. Commits and PR titles in English; merging only with a merge commit.** The
  repository is linked material of the submission, which is all in English, and a commit
  message cannot be changed without rewriting the history. Issues, PR bodies and reviews stay
  in Spanish. The merge commit carries the PR title in its body and GitHub does not allow
  leaving it empty with the default first line (it rejected it with a 422), so the title goes
  in English.
- **2026-11-14. Merging is done by a person, after approving.** Claude neither approves nor
  merges (`gh pr merge` is denied), and in auto mode the ask rule does not guarantee that a
  commit asks first (#4, #6): the net is human review, with "Approve" selected before the
  green button (#12). While the repository is private GitHub does not enforce it: of the seven
  PRs merged on the 14th before #12, only #5, #10 and #11 had an approval.
- **2026-11-14. Static site with precomputed data, on Cloudflare Pages.** The project is
  connected through Git from jofavalle's account, because Cloudflare only lists the
  repositories of whoever connects: every merge to `main` publishes itself. What is shown does
  not depend on the function under `/api/`, so that it stays up until 26 January 2027.
- **2026-11-14. The LLM generates the cards before publishing and does not decide the
  order.** One model only (Gemini, free tier). The numbers of the charts come from code; the
  levels are assigned by the team by hand; and the dashboard generates neither safety
  measures nor scenarios. Live questions only go in if what is committed is published in
  time (#16).
- **2026-11-14. The original PSI files are not versioned**: they carry metadata with people's
  names. The scripts and what they produce are versioned.
- **2026-11-15. The situation is posed by whoever uses the dashboard, and the order is by how
  direct the evidence is, not by level of risk.** The PSI records give neither probability nor
  severity. The view returns findings with their passage, not recommendations, and declares
  that a situation cannot be matched by atmosphere (#16, #45).
- **2026-11-15. The interface reads `site/data/`.** `site/data/fixture/` stays as the
  hand-written example of the data contract; its values are invented and the interface shows
  a notice when it reads them (#54).
- **2026-11-15. The layer goes to English, but names stay.** File names (`BITACORA.md`,
  `.github/higiene.py`), skill names and issue labels are not translated: renaming them would
  break open orders and merged PRs that quote them (#57, #58, #59).
